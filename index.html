FAQ

Questions fréquentes

Tout ce qu'il faut savoir avant de s'abonner.

C'est vraiment gratuit ?
Oui, totalement gratuit et sans compte requis. Le projet est open source, hébergé sur GitHub. Aucune publicité, aucune donnée revendue.
Le calendrier se met-il à jour automatiquement ?
Oui. En vous abonnant via un lien ICS, votre appli agenda vérifie régulièrement les mises à jour. Si les dates officielles changent, votre agenda se met à jour tout seul — vous n'avez rien à faire.
Compatible avec quelles applis ?
Toutes les applis supportant le format iCalendar (RFC 5545) : Apple Calendar (iPhone, iPad, Mac), Google Calendar, Outlook (desktop et web), Thunderbird, Fantastical, et la plupart des agendas Android.
Mes données sont-elles collectées ?
Non. Aucune donnée personnelle n'est collectée pour créer un compte ou vous suivre. Le serveur reçoit uniquement les requêtes HTTP standards pour servir les fichiers ICS.

Note sur le mode Avancé : si vous ajoutez des événements personnels, leur titre et leur date transitent dans l'URL générée et peuvent apparaître dans les journaux techniques du serveur. N'inscrivez pas d'informations sensibles.
Quelle différence entre les zones A, B et C ?
Les académies françaises sont réparties en trois zones pour éviter que tout le monde parte en vacances en même temps.

Zone A : Lyon, Bordeaux, Grenoble… — Zone B : Nantes, Lille, Strasbourg… — Zone C : Paris, Montpellier, Toulouse…

Utilisez la recherche de zone pour trouver la vôtre en tapant votre ville.
Et pour l'Alsace-Moselle ?
Les départements 57 (Moselle), 67 (Bas-Rhin) et 68 (Haut-Rhin) bénéficient de deux jours fériés supplémentaires : le Vendredi Saint et le 26 décembre (Saint-Étienne). Dans l'onglet Avancé, sélectionnez "Alsace-Moselle" pour les inclure.
Quelle différence entre Simple et Avancé ?
Simple : abonnement en 3 étapes guidées — vous choisissez votre appli, votre zone scolaire, et c'est tout. Vous recevez tout le calendrier.

Avancé : vous construisez un lien sur mesure en 5 étapes — profil, zones, catégories précises, rappels, et vos propres événements récurrents (anniversaires…).
À quelle fréquence le calendrier est-il mis à jour ?
Le calendrier est régénéré automatiquement tous les jours à minuit via un workflow GitHub Actions. Les données de vacances scolaires proviennent du Ministère de l'Éducation Nationale et sont vérifiées à chaque mise à jour.

Votre agenda se synchronise lui aussi régulièrement — toutes les heures sur iPhone, toutes les 12h sur Google Calendar — sans aucune action de votre part.
Je ne vois pas les vacances s'afficher dans mon agenda, pourquoi ?
Quelques causes fréquentes :

1. Votre agenda n'a pas encore synchronisé — attendez quelques minutes ou forcez une actualisation manuelle.
2. Le calendrier abonné est désactivé — vérifiez qu'il est coché/visible dans votre appli.
3. Vous avez téléchargé le fichier .ICS au lieu de vous abonner — dans ce cas les événements ne se mettent pas à jour automatiquement. Recommencez en cliquant "S'abonner".
4. Google Calendar peut prendre jusqu'à 24h pour la première synchronisation.
Comment désactiver ou supprimer le calendrier ?
iPhone / Mac : Réglages → Calendrier → Comptes → choisissez le compte → supprimez l'abonnement.

Google Calendar : Dans les paramètres de Google Calendar, rubrique "Autres agendas", cliquez sur les trois points à côté du calendrier → Désabonner.

Outlook : Calendrier → clic droit sur le calendrier dans la liste → Supprimer le calendrier.
Pourquoi l'abonnement s'ouvre sur une page blanche sur iPhone ?
C'est normal — Safari ouvre le lien webcal:// en arrière-plan et propose directement d'ajouter le calendrier via une alerte système. Si l'alerte n'apparaît pas :

1. Allez dans Réglages → Calendrier → Comptes → Ajouter un compte → Autre → Abonnement calendrier.
2. Collez l'URL copiée depuis la section "Voir le lien d'abonnement".
3. Appuyez sur Suivant, puis Enregistrer.
Puis-je utiliser ce calendrier dans mon propre projet ?
Oui. Le projet est open source (GitHub). Le fichier calendrier.json est disponible publiquement et peut être intégré dans n'importe quelle application. L'API /api/calendrier.ics supporte des paramètres de filtrage (zone, cats, alarm_feries…).

Voir le dépôt GitHub →
Une date est incorrecte, comment signaler ?
Les données proviennent du Ministère de l'Éducation Nationale. Pour signaler une erreur, ouvrez une issue sur GitHub — les corrections sont déployées rapidement.
